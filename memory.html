    记忆自我：峰终定律

    卡尼曼区分了「体验自我」与「记忆自我」。我们回忆起一段经历时，往往只记住它的峰值与 结尾，而忽略时长与其余部分——这就是影响幸福判断的峰终定律。

    体验自我 记忆自我 峰终定律

    两个自我

    谁在评价你的生活？

    体验自我

    在每时每刻实际感受当下——疼痛、快乐、紧张。它关注「此刻的连续体验」，但不做整体总结。

    记忆自我

    事后回顾并叙述这段经历，用记忆形成整体判断。它决定我们「是否满意」这段经历，却常常忽略时长与平淡片段。

    峰终定律

    体验由峰值与结尾决定
    体验强度曲线（记忆只记住峰与尾）

    记忆≈峰值 + 结尾，与体验总时长关系不大。

    经典实验

    让被试经历一段「痛苦的结尾」被改成「相对不那么难受」的延长版，他们反而给出更高评价——因为记忆自我记住了更平滑的结尾，即便总体体验更久。

    更短的痛 → 记作更糟
    延长但更轻的尾 → 记作更好

    峰终定律的应用

    设计体验与自我管理
    1. 服务设计：把资源投入到峰值与结尾，而非平均分配。
    2. 团队激励：为项目设计「高光时刻」与体面的收尾，强化正面记忆。
    3. 自我回顾：警惕「以峰终替代全部」的倾向，用数据与日志还原真实体验。
    4. 决策辅助：回忆快乐时，别只信记忆自我的一句话总结。
